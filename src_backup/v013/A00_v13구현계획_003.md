🌿 Smart Nature Wind – 작동 기능 스펙 요약서


---

🧩 1️⃣ 시스템 개요

Smart Nature Wind는
선풍기(PWM 팬)를 자연스러운 바람 패턴으로 제어하기 위한
ESP32 기반 시뮬레이션 컨트롤러입니다.

동작은 두 축의 제어 시스템으로 구성됩니다.

구분	제어 주체	기능 요약

🕹️ Motion Logic (M10)	센서(PIR)	팬의 작동 여부(ON/OFF) 결정
⏰ Simulation Mode (S10)	사용자/스케줄러	팬이 켜졌을 때 어떤 방식으로 동작할지 결정 (Continuous vs Schedule)



---

⚙️ 2️⃣ 동작 모드 정의

모드	설명	제어 주체	예시

Continuous Mode (연속 모드)	지정된 preset/intensity로 계속 작동	사용자 지정	‘산들바람 preset’으로 계속 작동
Schedule Mode (스케줄 모드)	시간대에 따라 preset/intensity 자동 전환	Scheduler	아침엔 약풍, 오후엔 강풍, 밤엔 수면풍



---

🧭 3️⃣ Motion(모션) 로직 정의

Motion은 팬을 켜거나 끄는 역할만 수행합니다.

항목	설명

감지 시	Motion Active → 팬 작동 허용
미감지 시	Motion Inactive → 팬 정지 (PWM=0)
우선순위	Motion이 OFF이면 다른 설정은 모두 무시됨
지속시간	마지막 감지 이후 일정 시간 유지 (active_duration_ms)
Motion Boost	감지 시 강도 일시적 가속 가능 (선택적)



---

🔄 4️⃣ 동작 우선순위 체계

1️⃣ Motion Logic (M10) → 팬 켜기/끄기 결정
2️⃣ Simulation Mode (S10) → Continuous/Schedule 선택
3️⃣ Simulation Engine (S10_Simulation) → 난류·PWM 계산 수행


---

🕹️ 5️⃣ 시나리오별 동작 결과

Motion	Mode	결과

ON	Continuous	지정 preset으로 계속 작동
ON	Schedule	시간대 preset으로 자동 전환
OFF	(모두)	팬 정지 (PWM=0)

🔄 8️⃣ tick() 루프 흐름

void CL_WS10_WindScapeSimulator::tick() {
    // 1. Motion 상태 확인
    bool motionActive = CL_M10_MotionLogic::isActive();

    // 2. Motion OFF → 즉시 팬 정지
    if (g_A10_config_root.motion.motionEnabled && !motionActive) {
        _sim.S10_stopFan();
        return;
    }

    // 3. Mode에 따라 preset 적용
    if (g_A10_config_root.system.mode == S10_MODE_SCHEDULED)
        CL_S10_Scheduler::tick(); // 스케줄 적용
    else
        _sim.S10_applyPreset(
            g_A10_config_root.sim.preset,
            g_A10_config_root.sim.intensity,
            g_A10_config_root.sim.variability
        );

    // 4. 물리엔진 tick
    _sim.S10_tick();
}
