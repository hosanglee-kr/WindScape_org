✅ 1. 핵심 개념

개념	설명

Preset (환경)	바람의 장소적 특성 (Ocean, Mountain 등)
Style (활용 목적)	사용자 상황 기반 세기/변동 스타일 (Sleep, Focus 등)
User Profile (작동 프로파일)	사용자가 만든 시간 분할 바람 시나리오 (segments)
Continuous Mode	연속 작동 모드 (웹/버튼에서 즉시 실행)
Schedule Mode	요일/시간 기반 자동 작동
Motion Logic	PIR/BLE 기반 사람 감지 → 바람 온/오프 조건
Auto-Off Timer	일정 시간 후 자동 종료


> 기존 선풍기와 차별점: 실제 자연 대기물리 시뮬레이션 + 사용자 맞춤 바람 프로필

✅ 2. 사용자 대상 주요 기능

🌬️ 자연풍 알고리즘

실제 자연 난류·돌풍·열기류 모델링

장시간 사용 시 적응 방지 → 시원함 유지

수면·집중 상황에서 불편 없는 풍속 변화


🟦 Continuous 모드 (즉시 작동)

UI or 버튼으로 실행

선택 항목:

Fixed Speed (0~100%)

Preset + Style 조합

User Profile 직접 실행 가능


마지막 설정값 자동 저장 (NVS)


🟨 Schedule 모드 (자동 운전)

요일별 / 시작~종료 시간 설정

여러 segment 운영

segment마다 설정 가능

preset+style

fixed speed

wind adjust (세부 조정)


일정 시간대 미지정 시 skip


🟥 User Profiles (사용자 장면 모드)

10개 저장 가능

각 Profile = 여러 Segment

Repeat 가능

구성 요소:

preset/style or fixed speed

motion 활용 여부

auto-off timer


예:

수면모드

집중모드

휴식모드

환기모드

활동모드



🟩 Motion 대응

PIR: 거동 감지

BLE: 사용자 기기 근접 인식

hold_sec 후 자동 off

Profile/Continuous/Schedule 모두 적용 가능


🟫 하드웨어 제어

PWM 팬 제어

온도/습도 센서(옵션)

PIR 센서

BLE 신호 기반 존재 감지
