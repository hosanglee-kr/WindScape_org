1️⃣ 시스템 개요

항목	내용

제품 개념	일반 USB 선풍기·탁상용 팬을 “자연풍 시뮬레이터”로 변환하는 스마트 컨트롤러
목적	일정한 기계적 바람이 아닌, 실제 자연의 리듬과 감각을 구현
주요 특징	바람 프리셋(Preset) + 스타일(Style) + 미세 조정(Adjust) + 자동 제어(Motion/Timer/Temp)
사용 환경	사무실, 서재, 침실, 침대 옆 협탁 등 소형 공간
조작 방식	Web UI 기반 상세 제어 + 물리 버튼 기반 간단 제어

4️⃣ 구성 데이터 스펙 요약

4.1 Preset (자연풍 프리셋)

코드	이름	특징	풍속 범위

COUNTRY	Country Breeze	잔잔하고 일정한 바람	0.7–3.4m/s
MEDITERRANEAN	Mediterranean	포근하고 따뜻한 바람	1.6–3.8m/s
OCEAN	Ocean	깊은 해풍, 리듬감	1.8–5.5m/s
MOUNTAIN	Mountain	고지대 거친 바람	2.2–7.5m/s
PLAINS	Plains	시원하고 강한 기류	4.0–8.8m/s
HARBOR_BREEZE	Harbor Breeze	부드러운 항구의 바람	2.2–5.3m/s
FOREST_CANOPY	Forest Canopy	숲속의 잔바람	1.3–4.0m/s
URBAN_SUNSET	Urban Sunset	온화한 도심의 바람	1.8–4.9m/s
TROPICAL_RAIN	Tropical Rain	강한 순환풍	3.1–8.0m/s
DESERT_NIGHT	Desert Night	건조하고 느린 기류	0.9–3.1m/s



---

4.2 Style (사용자 감성 스타일)

코드	이름	특성	설명

ACTIVE	활동형	강도↑, 난류↑	운동/집안일 시
FOCUS	집중형	강도↔, 변동↓	업무/공부 시
BALANCE	균형형	표준 세팅	일상 일반 모드
RELAX	휴식형	강도↓, 난류↓	휴식/저녁용
SLEEP	수면형	강도↓↓, 변동↓	수면/야간용



---

4.3 Adjust (미세 조정 항목)

wind_intensity : 기본 풍속(%) 미세 조정

gust_frequency : 돌풍 발생 빈도

wind_variability : 변동 폭

fan_limit/min_fan : 팬 속도 한계 및 최소값

turbulence_length_scale / intensity_sigma : 난류 파라미터

thermal_bubble_strength / radius : 열기포(상승기류) 강도



---

5️⃣ 스케줄 모드 (cfg_schedules_025_final.json)

항목	설명

period.enabled	요일 및 시간 조건 사용 여부
segments	시간대별 작동 패턴 (고정/프리셋/스타일)
autoOff	타이머·시간·온도 조건 기반 자동종료
motion	PIR/BLE 센서에 따른 자동 게이팅 제어


예시

23:00–07:00 Night Sleep

23:00~ → OCEAN + SLEEP (완만한 진입)

02:00~ → FOREST_CANOPY + SLEEP (조용한 안정 바람)

06:30 → autoOff by time

Temp ≥ 26°C 시 유지, 이하 시 종료



---

6️⃣ 사용자 프로파일 (cfg_uzOpProfile_025_final.json)

프로파일	용도	주요 특징

1. 수면모드	취침용	완만한 감속, 타이머/온도 종료
2. 집중모드	업무·공부	FOCUS 스타일, PIR/BLE 활성
3. 휴식모드	독서·TV	RELAX 스타일, 중간 강도
4. 환기모드	공기순환	일정 주기 ON/OFF 반복
5. 활동모드	가사·운동	강풍 ACTIVE, 근접 감지
6. 사용자 정의	예비 슬롯	Custom 정의용



---

7️⃣ AutoOff 제어 통합 사양

항목	설명

timer.enabled	일정 시간 후 자동 중지
offTime.enabled	특정 시각 도달 시 중지
offTemp.enabled	환경 온도 기준으로 제어 (예: 온도 낮아지면 정지)
priority	Timer > OffTime > Temp (기본 우선순위)



---

8️⃣ Motion 게이팅 로직

센서	필드	설명

PIR	enabled + hold_sec	인체 감지 시 지속 동작, 미감지 시 일정 시간 후 정지
BLE	enabled + RSSI threshold	등록된 기기 근접 시 동작 유지, 이탈 시 정지
